# 🚀 LAUNCH DAY — One-Page Checklist

Work top to bottom. Everything you need is already built and in this repo.
Estimated time: **30–45 minutes** to be live.
Files live in `pcos-planner-assets/` unless noted.

---

## ⏱️ Block 1 — Validate (10 min)
- [ ] On Etsy, search **"PCOS planner"** → sort by **Top reviews**. Confirm top listings have lots of sales/reviews (= demand) and listing count looks beatable.
- [ ] Check **"PCOS"** on Google Trends → flat or rising. ✅ Green light → continue.

## ⏱️ Block 2 — Open your Etsy shop (15 min) — *needs your ID + bank/card*
- [ ] Go to **etsy.com/sell** → "Open your shop."
- [ ] Shop name: **Cycle & Bloom** (or your pick from `pcos-planner-brand-and-calendar.md`).
- [ ] Add bank (payouts) + card (Etsy's small fees). Set country/currency.

## ⏱️ Block 3 — Create your first listing (10 min)
- [ ] **+ Add a listing** → upload `PCOS-Cycle-Symptom-Planner.pdf` as a **Digital download**.
- [ ] Upload listing images: `listing-1.png` … `listing-6.png` (drag in order).
- [ ] **Title / Tags / Description:** copy-paste from `pcos-planner-launch-kit.md` §3.
- [ ] Type: **Digital**. Category: Paper & Party → Paper → Planners.
- [ ] **Price $12** (set list price $16, then run a shop **sale** to $12).
- [ ] **Publish.** 🎉 You are now live and sellable.

## ⏱️ Block 4 — Free funnel (do today or tomorrow, ~30 min)
- [ ] Free **MailerLite** account → landing page (rebuild `landing-page.html` layout or deploy the file via Netlify Drop).
- [ ] Upload `FREE-PCOS-Daily-Tracker.pdf` for delivery.
- [ ] Automation: new subscriber → 3 welcome emails (copy in `pcos-planner-lead-magnet-funnel.md` §4).
- [ ] Free **Linktree** with 2 buttons: 🆓 Free tracker + 🛒 Planner.

## ⏱️ Block 5 — Social + first posts (~1 hr) — *needs your phone*
- [ ] Create **TikTok + Instagram + Pinterest** under your brand. Paste bios from `pcos-planner-brand-and-calendar.md` §3. Add Linktree.
- [ ] Install **CapCut** (free). Film Days 1–3 from the 30-day calendar (screen-record the planner; use the scripts in `pcos-planner-faceless-marketing-kit.md`). Post to all 3.

## 📅 Then: the 30-day run
- [ ] Post daily (calendar in `pcos-planner-brand-and-calendar.md` §4). Reply to comments. Don't judge before day 30.

## 🔓 Expansion (week 3–4, after a few sales)
- [ ] Add **PMDD planner** listing → copy + images in `pmdd-and-bundle-listing-copy.md`.
- [ ] Offer **Sage theme** as a free variant in the PCOS listing.
- [ ] Launch **$24 bundle** → upload the 3 planner PDFs + `Bundle-Welcome-Start-Here.pdf`, images `bundle-listing-1/2.png`.
